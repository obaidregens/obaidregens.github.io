# Fanfiction.Online — Source Discovery Guide

Research sources for `2024-01-01-fanfiction-online-build.md`.

## Repositories

### wp_ffonline
The main PHP framework repo.
- **`Custom-Routing` branch** — 298 commits, the real production codebase. Layer-by-layer WordPress replacement: custom router, template engine, asset bundler (PHP manifest + Python compiler), faceted search.
- **`master` branch** — 6 commits only, a theme snapshot. Not the production code.

### ffarchive_py
First-generation FFN scraper.
- Scrapy + MongoDB
- Bulk story/metadata ingestion from fanfiction.net

### ffn_scraper
Second-generation scraper.
- Flaresolverr for Cloudflare bypass
- SQLite database `UserData.db` — 8,378 authors scraped
- More targeted, author-level data collection

### fanfiction_online + beta
Deployed webapps (DigitalOcean droplet `167.99.11.178`).
- Production site and beta/staging variant
